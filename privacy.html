개인정보처리방침

본 방침은 Authorita-kr가 운영하는 개인용 ‘개인 캘린더 도우미’의 Google Calendar 연동에 적용됩니다.

1. 접근하는 정보

사용자가 승인한 범위에서 캘린더 식별 정보와 일정 제목, 시간, 설명, 장소, 참석자 등 일정에 포함된 정보를 조회할 수 있습니다. 연동 유지를 위해 OAuth 접근 토큰과 갱신 토큰을 사용합니다.

2. 이용 목적

일정 조회·요약·안내와 사용자가 요청하고 확인한 일정 관리에 사용합니다. 개인 정보를 판매하거나 광고 타기팅 목적으로 이용하지 않습니다.

3. 처리 위치와 외부 서비스

인증 정보와 연동 설정은 운영자의 개인 서버 환경에 보관합니다. 일정 조회 결과나 대화 내용은 요청 처리 과정에서 설정된 AI 제공자에 전달될 수 있으며, 텔레그램 등 설정한 메시징 채널로 전달될 수 있습니다. 각 서비스의 보관·처리 조건은 해당 서비스의 정책과 계정 설정에 따릅니다. 이 방침은 외부 제공자의 처리 방식을 대신 보증하지 않습니다.

4. 보관과 삭제

인증 정보는 연결을 유지하는 동안 보관됩니다. 일정 조회 결과가 포함된 대화 기록, 실행 로그 또는 백업은 해당 운영 환경의 보존 설정에 따라 남을 수 있으며 자동 즉시 삭제를 보장하지 않습니다. 운영자는 필요 없어진 인증 정보와 저장 기록을 삭제할 수 있습니다. 연결 해제만으로 기존 기록이나 Google Calendar 원본 일정이 삭제되지는 않습니다.

5. 접근 철회 및 삭제 요청

Google 계정의 서드 파티 연결 관리에서 앱 접근 권한을 철회할 수 있습니다. 저장 기록 삭제 등은 운영자에게 요청할 수 있습니다. 공개 문의에는 민감한 정보를 기재하지 마세요.

6. 공개 웹사이트

이 안내 사이트는 GitHub Pages에서 제공되며 로그인 입력 폼, 자체 분석 도구 또는 광고를 포함하지 않습니다. 호스팅 과정에서 GitHub가 접속 정보를 처리할 수 있습니다. GitHub 개인정보처리방침을 참고하세요. 캘린더 데이터와 OAuth 인증 정보는 이 사이트의 공개 파일에 포함하지 않습니다.

7. 문의 및 변경

운영자: Authorita-kr. 문의 페이지를 통해 연락할 수 있습니다. 기능이나 데이터 처리 방식이 변경되면 이 페이지를 갱신합니다.
